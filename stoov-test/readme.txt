================================================================================
  Stoov Bed 加热垫测试工具 - 使用说明
================================================================================

一、环境准备
------------

  1. 硬件连接
     - 使用 USB 转串口线连接电脑和加热垫设备
     - 确保设备已通电

  2. 浏览器要求
     - 推荐 Chrome/Edge 最新版（支持 Web Serial API）
     - 需要通过 HTTP 服务器打开（不能直接用 file:// 打开）
     - 安装为桌面应用后，下次直接打开方便测试。


二、连接设备
------------

  串口连接：
    1. 点击左上角「连接」按钮
    2. 在弹出的设备选择框中选择串口设备
    3. 连接成功后，状态灯变绿，显示"已连接"
    4. 页面会自动开始读取设备数据

三、测试模式说明
----------------

  页面提供两种测试模式，通过遥控面板右上角的「船形开关」切换：

  ┌──────────────────────────────────────────────────────┐
  │  🟢 测试遥控（测试的遥控PCBA板）                              │
  │                                                      │
  │  测试目的：验证遥控器面板各项控制功能是否正常           │
  │                                                      │
  │  检测项目：                                           │
  │    1. ON/OFF 功能     → 检测 OFF→ON 是否正常           │
  │    2. 时间调节功能     → 检测 2~12 小时档位              │
  │    3. 身体温度调节     → 检测 OFF 和 36°C 两档          │
  │    4. 脚温度调节       → 检测 OFF 和 40°C 两档          │
  │                                                      │
  │  操作方式：在加热面板上点击按钮调节各项参数              │
  │                                                      │
  └──────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────┐
  │  🔴 测试加热（测试加热PCBA板）                              │
  │                                                      │
  │  测试目的：验证设备内部各项参数是否在合格范围内         │
  │                                                      │
  │  检测项目：                                           │
  │    1.  设备 ID          → 自动读取                     │
  │    2.  故障代码          → 0x00 = 正常                  │
  │    3.  身体温度传感器     → 默认 15~30°C               │
  │    4.  脚温度传感器       → 默认 15~30°C               │
  │    5.  身体设置温度       → 0 或 25~36°C               │
  │    6.  脚设置温度         → 0 或 25~40°C               │
  │    7.  运行状态           → 需出现"运行中"和"已关闭"     │
  │    8.  设置运行时间       → 1~12 小时                   │
  │    9.  身体关电流(ADC)    → 默认 0~80                  │
  │    10. 身体加热电流(ADC)  → 默认 1800~3000   //待定          │
  │    11. 脚关电流(ADC)      → 默认 0~80                  │
  │    12. 脚加热电流(ADC)    → 默认 1800~3000  //待定          │
  │                                                      │
  │  检测方式：设备自动上报数据，系统自动判定合格/不合格     │
  │                                                      │
  └──────────────────────────────────────────────────────┘


四、测试操作流程
----------------

  【测试的遥控PCBA板 - 测试遥控】操作步骤：

  步骤 1：连接串口
          点击「连接」→ 选择串口设备

  步骤 2：输入条码
          在遥控面板上方的"条码输入"框中扫描或输入产品条码
          （至少 6 位字符，输入后"开始测试"按钮会激活）

  步骤 3：选择模式
          确保船形开关在左侧「测试遥控」位置

  步骤 4：开始测试
          点击「⏵ 开始测试」按钮
          测试面板显示 4 项待检测项目

  步骤 5：操作加热面板
          在遥控面板上依次操作：
            a) 点击电源按钮 → 切换 ON/OFF（需先 OFF 再 ON）
            b) 点击时间调节 → 调整到 2~12 小时
            c) 点击身体温度调节 → 调到 0°C 和 36°C
            d) 点击脚部温度调节 → 调到 0°C 和 40°C
          每项通过后，测试面板对应项显示 ✅ PASS

  步骤 6：保存结果
          全部通过后，点击「💾 保存」按钮
          测试结果会自动通过 MQTT 发送到后端


  【测试加热PCBA板 - 测试加热】操作步骤：

  步骤 1：连接串口
          同上

  步骤 2：输入条码
          同上

  步骤 3：选择模式
          将船形开关拨到右侧「测试加热」位置

  步骤 4：开始测试
          点击「⏵ 开始测试」按钮
          系统自动请求设备信息，等待设备上报数据

  步骤 5：等待检测
          设备会自动上报温度、电流、状态等数据
          系统自动判断每项是否合格，实时显示在测试面板
          部分项目需要切换加热开关来验证（如电流检测）

  步骤 6：保存结果
          全部通过后，点击「💾 保存」按钮


五、键盘快捷键（测试加热PCBA板专用）
------------------------------

  当船形开关在「测试加热」位置时可使用：

    按键            功能
    ──────────────────────────
    P               开关电源 ON/OFF
    ↑ / ↓           身体温度 ±1°C
    ← / →           脚部温度 ±1°C
    Shift + ↑       时间 +1 小时
    Shift + ↓       时间 -1 小时


六、电流范围设置
----------------

  点击「⚙ 设置」按钮可调整电流合格范围（需要密码）
  默认密码：1234

  可调整参数：
    身体加热关电流范围    (默认 0~80 ADC)
    身体加热开电流范围    (默认 1800~3000 ADC)
    脚部加热关电流范围    (默认 0~80 ADC)
    脚部加热开电流范围    (默认 1800~3000 ADC)
    身体温度传感器范围    (默认 15~30°C)
    脚部温度传感器范围    (默认 15~30°C)

  输入格式：min-max（如 "0-100"）


七、下载测试数据
----------------

  点击「📥 下载数据」按钮，从服务器下载已保存的测试数据 CSV 文件
  （需要部署在 www.unito.top 域名下或能访问对应 API）


八、MQTT 测试结果上报
--------------------

  测试结果通过 MQTT 自动发送到以下主题：

    模式        普通测试 Topic                  保存测试 Topic
    ─────────────────────────────────────────────────────────
    测试遥控    /unito/stoov/heating-bed/       /unito/stoov/heating-bed/
                yaokong                         save/yaokong

    测试加热    /unito/stoov/heating-bed/       /unito/stoov/heating-bed/
                heating                         save/heating

  数据格式（JSON）：
    {
      "mode": "external" | "internal",
      "barcode": "条码内容",
      "timestamp": "ISO 时间戳",
      "deviceId": "设备ID（仅 internal 模式）",
      "deviceVer": "版本号（仅 internal 模式）",
      "items": { "1": "ok", "2": "ok", ... }
    }


九、常见问题
------------

  Q: 点击"连接"没有反应？
  A: 请检查是否通过 HTTP 服务器打开页面（不是 file://），
     并使用 Chrome/Edge 浏览器。

  Q: "开始测试"按钮灰色无法点击？
  A: 需要在条码输入框输入至少 6 位条码，按钮才会激活。

  Q: 测试的遥控PCBA板某项一直不通过？
  A: 检查操作顺序：ON/OFF 必须先 OFF 再 ON；温度需要调到
     指定值（身体 0°C 和 36°C，脚部 0°C 和 40°C）。

  Q: 测试加热PCBA板电流检测不通过？
  A: 可能是电流范围设置不匹配，点击「⚙ 设置」调整合格范围
     （ADC 值而非实际电流值）。
