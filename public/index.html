📘 关于本站

本网站为个人非经营性技术学习站点，主要用于：

  • 学习与实践 TCP/IP、WebSocket、MQTT 等网络协议编程
  • 可视化展示自建物联网设备（如 ESP32、树莓派）采集的环境数据
  • 记录 Postman、Wireshark、Docker、VS Code 等开发工具的使用技巧

所有内容均为学习用途，不涉及商业行为，亦不收集用户个人信息。
